두 사람의 이름을 입력하세요.

이름 궁합 테스트 사용법

두 사람의 이름을 입력하고 궁합 보기를 누르면 궁합 점수(%)와 어울리는 메시지를 보여드립니다. 친구, 연인, 썸 타는 상대와 가볍게 즐기고 결과를 공유해 보세요. 같은 이름 조합은 항상 같은 결과가 나옵니다.

이름 궁합, 어떻게 나오나요?

전통적인 이름 궁합 놀이는 두 이름의 획수를 더해 가며 마지막 한 자리 숫자를 만드는 방식입니다. 이 테스트는 두 이름을 조합해 일정한 규칙으로 점수를 계산하므로, 같은 이름끼리는 언제 해도 결과가 같습니다.

이름 궁합은 과학적 근거가 없는 재미용 콘텐츠입니다. 결과에 너무 의미를 두지 말고 즐겨 주세요. 실제 인연은 서로를 향한 마음과 노력으로 만들어집니다.
