## 배열 논리 (왜 이 순서인가)

1. **Wave 1은 전부 🟢 + 제작 쉬움**: 요율변동·의료 리스크 있는 것(연봉·육아 등)을 초기에서 배제 → 유지보수 0으로 빠르게 페이지 수 확보 + 인덱싱.
2. **애드센스는 Wave 2 중반에 신청**: 도구 20개+ 각 설명 콘텐츠가 쌓여야 "저품질" 거절 회피.
3. **RPM은 Wave 2에 집중 배치**: 금융(대출·연봉·복리)·비즈니스(마진·부가세)로 트래픽당 수익을 끌어올림.
4. **Wave 3은 재방문·바이럴·시너지**: 운세·궁합(매일/공유)로 볼륨, 탄생화·탄생석으로 **TECHA 자사 상품 연계**(애드센스 단독 탈피 = 생존성 조건 충족).
5. **🌍 비중 관리**: Top 30의 약 60%가 글로벌 공용 → Phase 2 영어 확장 시 그대로 재활용(수익 3~5배 레버).
