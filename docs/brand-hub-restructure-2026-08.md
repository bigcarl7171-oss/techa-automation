# 브랜드 허브 전환 구성안 (2026-08-06)

목적이 바뀌었다. 인스타그램·홍보글 등 **테차의 모든 외부 접점이 이 사이트로 모인다.**
1차 목적은 판매가 아니라 **브랜드 강화**이고, 들어온 사람이 첫 눈에
"여기가 어디고 뭘 할 수 있는 곳인지" 알아야 한다.

이 문서는 리뉴얼 실행 전 **검토용 제안서**다. 확정 후 실행 계획으로 옮긴다.

## 1. 지금 구조 진단 (실측)

로컬에서 실제 렌더링해 측정한 값이다.

| 구간 | 모바일 390×844 | 데스크톱 1440×900 |
|---|---|---|
| 히어로 | 178px 시작 (첫 화면) | 137px 시작 (첫 화면) |
| 브랜드 한 줄 | 425px (첫 화면) | 419px (첫 화면) |
| 신뢰 3종 | 488px, **높이 251px** (첫 화면) | 461px (첫 화면) |
| 상황 카드(선물 큐레이션 포함) | **860px — 첫 화면 밖** | 644px (첫 화면) |
| 매거진(꽃 이야기) | 1321px (1.6스크롤) | 945px (1.1스크롤) |
| 전체 도구 표 | 2135px, **높이 1884px** | 1268px |
| 문서 전체 | 4921px | 3296px |

**모바일 첫 화면(844px)에 담긴 것**: 계산기 카피 히어로 + 브랜드 한 줄(43px) +
"로그인 없이 / 입력값 안 보냄 / 근거 표기" 3종.

즉 **첫 화면의 30%(251px)를 계산기 신뢰 문구가 쓰고 있고**, 브랜드는 43px짜리
한 줄이 전부다. 인스타 유입은 대부분 모바일인데, 가장 브랜드다운 요소인
선물 큐레이션·꽃 이야기는 전부 스크롤 아래에 있다.

### 문구가 답하는 질문이 틀렸다

현재 히어로: **"계산할 것도, 심심풀이도. 테차 서랍 하나면 충분해요."**

인스타에서 넘어온 사람은 이미 테차를 **꽃 브랜드로 알고** 클릭한다.
그 사람이 첫 화면에서 만나는 건 계산기 홍보와 `금융·재테크`·`건강`·`텍스트 도구`
사이드바다. "잘못 들어왔나?"가 먼저 나온다.

> 참고: 히어로 **이미지는 이미 브랜드다** (공방에서 꽃다발을 든 사진).
> 이미지와 문구가 서로 다른 사이트를 설명하고 있다. 자산은 이미 있고 카피만 어긋났다.

### 이건 과거엔 옳은 설계였다

`renewal-plan-2026-07.md` §4는 **"브랜드는 2차, 도구가 1차"**를 명시적으로 택했다.
이유도 적혀 있다 — *"계산기 찾아온 사람이 첫 스크롤에 꽃 글을 만나지 않게."*

그 판단은 **검색 유입**을 가정했을 때 옳다. 지금 바뀐 건 설계가 아니라 **유입 가정**이다.

## 2. 핵심 문제: 관객이 둘인데 입구가 하나다

| | A. 검색 유입 | B. 브랜드 유입 (새 목표) |
|---|---|---|
| 어떻게 오나 | "만 나이 계산기" 검색 | 인스타 프로필·홍보글 링크 |
| 테차를 아나 | 모른다 | **이미 안다 (꽃 브랜드로)** |
| 원하는 것 | 계산 결과 하나 | 이 브랜드가 뭘 하는 곳인지 |
| 지금 대접 | 좋음 | **나쁨** |

**하면 안 되는 것: 브랜드 100%로 갈아엎기.**
도구 22개가 이 사이트의 유일한 자연 유입 엔진이다. 계산기를 첫 화면에서 치우면
검색 유입이 죽고, 그러면 인스타 팔로워에게만 보여주는 브로슈어가 된다.
그건 이미 스마트스토어가 하고 있다.

**할 것: 첫 화면에서 관객을 나눈다.** 히어로를 두고 싸우지 말고, 갈림길을 만든다.

## 3. 제안 구조 — "브랜드가 먼저 말하고, 두 갈래로 보낸다"

### 3.1 첫 화면 재구성

```
┌─────────────────────────────────────────────┐
│  [테차 로고]              [스마트스토어 →]   │
├─────────────────────────────────────────────┤
│                                             │
│   시들지 않는 꽃을 만드는 테차입니다          │  ← 정체성 (브랜드 확인)
│   선물 고르는 일부터, 매일의 계산까지          │  ← 역할 (활용도)
│   필요한 걸 꺼내 쓰는 서랍을 열어뒀어요        │
│                                             │
│   ┌──────────────┐  ┌──────────────┐        │
│   │ 🎁 선물 찾기  │  │ 🧰 도구 쓰기  │        │  ← 갈림길
│   │ 상황별 추천   │  │ 계산기 22개   │        │
│   └──────────────┘  └──────────────┘        │
│                                             │
└─────────────────────────────────────────────┘
```

- **1행이 브랜드 정체성**을 확정한다 → B 관객의 "여기 맞나?" 해소
- **2·3행이 활용도**를 말한다 → 두 관객 모두에게 "여기서 뭘 하는지" 전달
- **버튼 2개가 즉시 분기**한다 → A는 오른쪽, B는 왼쪽. 서로 방해하지 않음
- 신뢰 3종(로그인/입력값/근거)은 **도구 영역 위로 이동** — 계산기를 쓸 사람에게만
  필요한 말이다. 첫 화면 251px을 브랜드에 돌려준다

### 3.2 히어로 문구 후보

| 안 | 문구 | 성격 |
|---|---|---|
| **A (추천)** | **시들지 않는 꽃을 만드는 테차입니다.**<br>선물 고르는 일부터 매일의 계산까지, 필요한 걸 꺼내 쓰세요. | 정체성 선언 후 역할. B 관객에게 가장 명확 |
| B | **꽃 선물, 덜 고민하게.**<br>테차가 고르고, 세어보고, 오래 두는 법까지 알려드려요. | 편익 중심. 브랜드명이 늦게 나옴 |
| C | **테차가 만든 서랍입니다.**<br>선물 고를 때도, 계산할 때도 열어보세요. | 서랍 은유 유지. 짧지만 "테차가 뭐 하는 곳인지" 안 알려줌 |

A를 추천한다. **B 관객에게 "시들지 않는 꽃"이라는 브랜드 핵심을 첫 문장에서 주고**,
동시에 A 관객에게 "매일의 계산"으로 도구 사이트임도 알린다.
C는 이미 테차를 아는 사람에게만 통해서, 검색 유입을 버리는 문구다.

### 3.3 정보 구조를 2층으로

지금은 카테고리 8개가 평평하게 나열되고, 정작 가장 브랜드다운 `생활` 카테고리에는
도구가 **1개**뿐이다(선물 큐레이션). 브랜드 관련 도구가 `운세·감성`, `날짜·시간`에
흩어져 있어 묶음으로 보이지 않는다.

**2층으로 재편:**

```
🎁 선물·기념일          ← 브랜드 영역. 첫 화면 갈림길의 왼쪽
   상황별 선물 큐레이션 / 월별 탄생화·꽃말 / 월별 탄생석
   D-Day 계산기 / 시들지 않는 꽃 관리법

🧰 생활 도구 (18개)      ← 유입 엔진. 갈림길의 오른쪽
   날짜·시간 / 계산·변환 / 금융·재테크 / 건강 / 운세·감성 / 텍스트 / 재미·추첨
```

이러면 B 관객이 왼쪽만 봐도 **테차가 선물 브랜드라는 인상이 구조로 전달된다.**
A 관객의 검색 진입 경로(개별 도구 페이지)는 전혀 건드리지 않으므로 SEO 손실이 없다.

### 3.4 브랜드 증명 밴드 추가

첫 화면 갈림길 바로 아래에, 지금 `/about/`에 묻혀 있는 것들을 꺼낸다.

- 실제 상품 이미지 3~4장 (프리저브드·비누꽃·무드등·용돈박스)
- 한 줄 소개: 경기 고양 공방, 조소 전공 디자이너 직접 제작
- 스마트스토어 CTA

지금은 브랜드 서사가 43px 한 줄 + `/about/` 클릭 뒤에만 있다.
인스타에서 온 사람의 90%는 `/about/`을 안 누른다.

## 4. 같이 고쳐야 할 것

### 4.1 `/care/`가 고아 페이지다

`시들지 않는 꽃 관리법` 페이지(프리저브드·비누꽃·실크·다육이 4종 관리법)는
**sitemap.xml에는 있는데 사이트 안 어디에서도 링크되지 않는다.**
홈 사이드바에도, 푸터에도, 도구 목록에도 없다. 제품 QR로만 도달 가능하다.

브랜드 관점에서 이건 가장 아까운 자산이다 — 구매 후 관리법은 **테차가 판매자가
아니라 전문가임을 증명하는 콘텐츠**다. `선물·기념일` 묶음에 넣어 노출시킨다.

### 4.2 문구 정합성

| 위치 | 현재 | 문제 |
|---|---|---|
| `<title>` | 계산부터 심심풀이까지, 테차가 만든 22가지 | 인스타 공유 시 미리보기가 계산기 사이트로 보임 |
| `og:description` | 무료 계산기·심심풀이 모음 | 위와 동일. **인스타 링크 미리보기가 첫인상이다** |
| `/about/` h2 | "테차 서랍은 어떤 곳인가요?" → 계산기 설명부터 | 브랜드 소개가 아니라 도구 설명서 |

OG 태그는 **인스타 프로필 링크의 썸네일**로 노출되므로 리뉴얼 1순위다.

### 4.3 유입 측정

`techa-kr-funnel.md`의 UTM 규칙을 홈으로도 확장한다.

```
인스타 프로필  techa.kr/?utm_source=instagram&utm_medium=bio
홍보 게시물    techa.kr/?utm_source=instagram&utm_medium=post&utm_campaign=<주제>
```

갈림길 버튼 2개에 `TECHA.track("entry_choice", { path: "gift" | "tools" })`를 붙이면
**"브랜드 유입이 실제로 어느 쪽을 누르는가"**가 데이터로 남는다.
3개월 뒤 이 비율이 다음 구조 판단의 근거가 된다.

## 5. 지켜야 할 선 (기존 원칙과의 충돌 점검)

`techa-kr-funnel.md` §5는 **"홈에서 상품을 직접 팔지 않는다"**고 못박았다.
이번 제안은 그 선을 넘지 않는다.

- 갈림길 왼쪽은 **선물 큐레이션 도구**로 보낸다 — 상품 진열이 아니라 추천 도구다
- 브랜드 밴드는 **누가 만드는지 보여주는 것**이지 구매 유도 배너가 아니다
- 스마트스토어 CTA는 지금도 상단에 있다 (신규 아님)

즉 **"브랜드를 설명하는 것"과 "상품을 파는 것"을 구분**해서, 전자만 강화한다.

## 6. 실행 순서 (확정 후)

| 단계 | 내용 | 위험 |
|---|---|---|
| 1 | OG/title/description 문구 교체 | 없음. 즉시 효과(인스타 미리보기) |
| 2 | 히어로 문구 A안 적용 + 신뢰 3종 아래로 이동 | 낮음. CSS·문자열 |
| 3 | 갈림길 버튼 2개 + `entry_choice` 이벤트 | 낮음 |
| 4 | 카테고리 2층 재편 (`site.js` APPS/CATS) | 중간. 홈 렌더링 로직 연동 |
| 5 | 브랜드 증명 밴드 (상품 이미지 필요) | **이미지 준비 필요** |
| 6 | `/care/` 내비게이션 연결 | 없음 |

1~3단계만 해도 첫인상 문제의 대부분이 해결된다. 4~5는 이미지 준비와 함께 진행.

## 7. 결정이 필요한 것

1. **히어로 문구** — A/B/C 중 선택 (A 추천)
2. **브랜드 밴드 이미지** — 상품 사진 3~4장을 쓸 수 있는지 (스마트스토어 것 재사용 가능한지)
3. **카테고리 2층 재편** — 지금 할지, 1~3단계 먼저 하고 반응 보고 할지
4. **`전체 도구 22개` 표기 유지 여부** — 브랜드 허브로 가면 개수 자랑이 덜 중요해짐
