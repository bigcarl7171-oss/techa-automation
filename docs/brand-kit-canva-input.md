# 테차 툴즈 — Canva Brand Kit 입력용 스펙

Canva는 API로 Brand Kit(브랜드센터)을 만드는 기능을 제공하지 않아, 아래 값을 그대로 복붙하며
**Home → Brand → Brand Kits → 새 Brand Kit 추가**에서 직접 입력하면 됩니다. `DESIGN-techa.md`에서
정리한 실제 사이트 토큰 그대로이며, 입력 순서는 Canva Brand Kit 화면 흐름(로고 → 컬러 → 폰트)에 맞췄습니다.

## 1. Brand Kit 이름
```
테차툴즈
```

## 2. 로고
사이트에 이미 있는 파일을 그대로 업로드하면 됩니다.
- 아이콘(정사각): `assets/icons/icon-512.png` (512×512), `assets/icons/icon-192.png` (192×192)
- 파비콘: `favicon.ico`
- 워드마크는 별도 이미지 파일이 없고 텍스트로만 존재합니다 — "테**차** 툴즈" (가운데 "차" 글자만 블루 #6E82A6). Canva에 로고로 올리려면 이 워드마크를 Canva에서 텍스트+컬러로 새로 만들어 로고 이미지로 내보내는 과정이 필요합니다.

## 3. 컬러 팔레트
이름과 hex를 Canva 컬러 추가 화면에 그대로 입력하세요. 1~5번이 핵심 브랜드 컬러(코드 주석에 있던 공식 네이밍), 6번 이후는 실제 화면에서 자주 쓰이는 보조 톤입니다.

| 순서 | 이름 (Canva에 입력) | HEX | 용도 |
|---|---|---|---|
| 1 | 수국 블루 (Hydrangea Blue) | `#6E82A6` | 신뢰·내비게이션·링크·포커스 (메인 액센트) |
| 2 | 무드등 앰버 (Mood-lamp Amber) | `#EFB054` | 버튼·CTA·강조 (액션 액센트) |
| 3 | 크림 페이퍼 (Cream Paper) | `#FAF7F1` | 배경(캔버스) |
| 4 | 공방 브라운 (Workshop Brown) | `#3A322B` | 본문 텍스트(잉크) |
| 5 | 잎사귀 그린 (Leaf Green) | `#7C8B6F` | 확정 상태 (예약, 아직 화면엔 미사용) |
| 6 | 블루 소프트 | `#EEF1F6` | 블루 배경 틴트 |
| 7 | 앰버 소프트 | `#FBEECF` | 앰버 배경 틴트 |
| 8 | 카드 화이트 | `#FFFDF9` | 카드 표면 (순백 아님, 웜톤) |
| 9 | 헤어라인 | `#E7E1D6` | 테두리/구분선 |
| 10 | 뮤트 텍스트 | `#857C70` | 보조 텍스트 |

## 4. 폰트
Canva 브랜드 폰트에 "헤딩용"과 "본문용"을 각각 등록하세요.

| 역할 | 폰트명 | 비고 |
|---|---|---|
| 헤딩(Heading) | **Gowun Batang** (구운바탕) | 세리프. 로고/H1~H3에 사용. Canva 폰트 라이브러리에 기본 포함이면 그대로 선택, 없으면 [Google Fonts](https://fonts.google.com/specimen/Gowun+Batang)에서 받아 Pro 계정으로 업로드 |
| 본문(Body) | **Pretendard** | 산세리프. 버튼·라벨·본문 전체에 사용. Canva에 없을 가능성이 높아 [Pretendard 공식 배포처](https://github.com/orioncactus/pretendard)에서 받아 업로드 필요 |

두 폰트 모두 무료 라이선스라 업로드에 법적 제약은 없습니다.

## 5. 브랜드 보이스 (참고용, Canva에 별도 입력란이 있다면)
- 톤: 실용적, 친근함, 담백함 — 과장된 세일즈 카피 없이 도구 사용법을 바로 안내
- 태그라인: "간단하고 편리한 생활 도구 모음"
